# HIV Drug Resistance Mapping with JupyterLite

These notebooks are designed for learners and epidemiologists who want to understand HIV drug resistance fundamentals and then turn study-level HIV drug-resistance surveillance data into transparent country-level maps and applied teaching examples.

Start with **00_hiv_drug_resistance_fundamentals.ipynb** for a visual primer on HIV drug resistance, then continue to **01_data_coverage.ipynb**, **02_global_tdr_choropleth.ipynb**, **03_drug_class_and_time.ipynb**, and **04_pediatric_hivdr_mch_case_study.ipynb**.

Notebook 04 is an MCH-centered pediatric HIVDR case study inspired by the August 19, 2026 MCH Office Hours presentation *HIV Drug Resistance in MCH Populations* by Spencer Lloyd, MPH, MD; Laura Broyles, MD; and Jason Bacha, MD. It uses presentation-derived pediatric examples for teaching and Stanford HIVDB for resistance-interpretation concepts.

The default surveillance data are a reproducible **2015 published snapshot** associated with Stanford HIVDB, not the current >120-country surveillance map. The repository README explains how to ingest a newer official machine-readable export when one is available.
