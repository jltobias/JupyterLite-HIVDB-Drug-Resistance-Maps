# HIV Drug Resistance Mapping with JupyterLite

These notebooks are designed for learners and epidemiologists who want to understand HIV drug resistance fundamentals and then turn study-level HIV drug-resistance surveillance data into transparent country-level maps.

Start with **00_hiv_drug_resistance_fundamentals.ipynb** for a visual primer on HIV drug resistance, then continue to **01_data_coverage.ipynb**, **02_global_tdr_choropleth.ipynb**, and **03_drug_class_and_time.ipynb**.

The default surveillance data are a reproducible **2015 published snapshot** associated with Stanford HIVDB, not the current >120-country surveillance map. The repository README explains how to ingest a newer official machine-readable export when one is available.
