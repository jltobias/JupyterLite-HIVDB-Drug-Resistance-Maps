# HIV Drug Resistance Mapping with JupyterLite

These notebooks are designed for epidemiologists learning how to turn study-level HIV drug-resistance surveillance data into transparent country-level maps.

Start with **01_data_coverage.ipynb**, then continue to **02_global_tdr_choropleth.ipynb** and **03_drug_class_and_time.ipynb**.

The default data are a reproducible **2015 published snapshot** associated with Stanford HIVDB, not the current >120-country surveillance map. The repository README explains how to ingest a newer official machine-readable export when one is available.
